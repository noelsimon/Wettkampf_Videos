# Videodateien

Hier die Videos ablegen, benannt nach der Routennummer: `Q3.mp4`, `Q4.mp4` … `Q11.mp4`.

- Format: **MP4 (H.264)** läuft auf allen Handys und Browsern. `.mov` vom iPhone vorher umwandeln.
- GitHub erlaubt max. **100 MB pro Datei**. Größere Videos verkleinern (z. B. 720p) oder
  in eine Cloud legen und in `videos.js` den Link eintragen.
